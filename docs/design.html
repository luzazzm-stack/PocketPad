The rules

User-friendly, defined

“Friendly” is a checklist here, not a mood. Every screen above and below obeys all six — if a built screen breaks one, it goes back.

RuleWhat it means in practice
One job per screen Each screen asks exactly one thing of you: connect, or play. Never two.
No jargon, anywhere “Waiting for your phone”, never “listening on UDP 46821”. Ports, drivers and tokens are for the fine print, not the interface.
The next step is always on screen Waiting screen tells you to open the phone app. Connected screen tells you to start the game. You never have to remember what comes next.
Errors say what to do “That code has expired — read the new one off the PC window.” Every error names the fix, or fixes itself with one button.
Big targets, readable far away Address and code sized to read from the couch; every phone button sized for thumbs, not cursors.
The happy path is zero typing Scan the QR, tap Connect. Typing is the fallback, not the routine.

App One · Windows

“PocketPad for PC” — a real window

One window, two states, zero terminal. The address and code are huge — readable from across the room while you hold your phone. A QR code makes typing optional: point the phone's scanner at it and you're connected.

The fine print

Decisions baked into this design

DecisionWhy
Name: “PocketPad for PC” “Link” read as a web link and caused real confusion. The window title, desktop icon and manual will all say PocketPad for PC.
WPF, not web tech Native Windows app, ~1 MB, instant start, no browser engine eating the 7.5 GB RAM this laptop has while a game runs.
QR pairing both ends Kills the typing step that produced every support question so far. Manual entry stays as the fallback.
Tray, not taskbar The window can't be lost behind a fullscreen game; a green tray icon means connected.
Console app retired It remains in the repo as a developer tool only. Users never see it again.
Approve this page and the build starts: Windows app first, then the phone update, then the manual is rewritten from the new screens.
