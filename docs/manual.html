PocketPad

Turn your Android phone into a wireless game controller for this PC — and into a trackpad when you need to click something.

ON THE PC

PocketPad Link — the small window that shows your address and code, and pretends to be an Xbox controller so games just work.

◀ ─── Wi-Fi ─── ▶

ON THE PHONE

PocketPad — the buttons you actually touch. Also holds the trackpad for driving Windows.

Section One

Playing a game

Four steps, every time. After the first run it takes about twenty seconds.

  1. Open PocketPad Link on the PC

    Double-click PocketPad Link on your desktop. A small black window opens and shows a PC address and a Code.

    Leave this window open the whole time you play. Closing it disconnects the controller.

  2. Check the phone is on the same Wi-Fi

    The phone and the PC have to be on the same network — the same router, or the PC's own hotspot. They can't find each other otherwise.

  3. Open PocketPad on the phone and type both values

    Type the PC address in the top box and the Code in the bottom box, exactly as the PC window shows them. Then tap Connect.

    The code is new every time you open PocketPad Link, so check the window rather than typing yesterday's.

  4. Start your game

    The PC window turns green and says CONNECTED. Your phone is now a controller — start the game as normal and it will be detected as an Xbox controller.

Hold the phone sideways in both hands. Left thumb on the arrows, right thumb on the coloured buttons — exactly like a real gamepad.

The number under the Mouse button

That's your delay, measured live. Under 20 ms shows green and feels instant. If it climbs into the amber, move closer to the router — something is congesting the Wi-Fi.

Section Three

Trackpad mode

A controller can't double-click a game icon or close a pop-up. Tap Mouse at the top of the gamepad and the phone becomes a laptop-style trackpad instead.

Nothing gets stuck

Switching between gamepad and trackpad releases every button first, so a held punch never carries over into Windows and a held click never carries into a match.

Section Four

If something goes wrong

Almost every problem is one of these five, and the fix is usually the first thing listed.

What you seeWhat to do
Connect does nothing, or it spins and gives up Check the phone and PC are on the same Wi-Fi. Then re-read the PC address — a single wrong digit is the usual cause.
"Rejected: token" The code changed. Look at the PocketPad Link window again and type the code it shows right now.
Connected, but the game ignores it Start PocketPad Link before the game. Many games only look for controllers when they launch — restart the game.
The delay number is high or amber Move nearer the router, or stop anything downloading. On a busy network, the PC's own hotspot is often faster.
It disconnects when the screen dims PocketPad keeps the screen awake by itself, but a battery saver can override that. Exclude PocketPad from battery optimisation in Android settings.

Why games accept it

PocketPad Link creates a real virtual controller through the ViGEm driver, so Windows and every game see genuine Xbox controller hardware. There is nothing to configure inside the game.
