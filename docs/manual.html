How to play with PocketPad

Your phone becomes the controller. Your PC runs the game. The fastest way to connect is scanning a QR code — no typing at all.

BLUE = do this on the PC GREEN = do this on the phone

On this PC

PocketPad for PC

A normal Windows program — its icon is on your desktop. Nothing to do with web links or browsers. You double-click it.

On your phone

PocketPad

The Android app with the same icon, in your app drawer. This is the controller you hold.

Getting the apps — one time

Both installers are on the project's Releases page (github.com/luzazzm-stack/PocketPad → Releases). After this you never do it again.

WhereWhat to do
PC Download PocketPad-Setup.exe and double-click it. If Windows shows “Windows protected your PC”, click More info → Run anyway (the app isn't signed yet — that's all it means). Click through the installer: it puts the icon on your desktop, installs the controller driver (approve the Windows prompt if one appears), and allows the app through the firewall — nothing to configure by hand. Nothing else to install: not even .NET.
Phone Download PocketPad.apk on the phone and open it. If Android asks about installing unknown apps, allow it for your browser and continue. The PocketPad icon appears in your app drawer.
1

On the PC

Double-click “PocketPad for PC” on the desktop

This window opens. Everything you need is on it:

The amber number is your PC address · the pink code changes every time you open the app · the QR square is the shortcut that skips typing

Keep this window open while you play. Closing it just tucks it away next to the clock (bottom-right of Windows) — the controller keeps working. To quit completely: right-click that small icon → Quit.

On the phone

Open PocketPad and scan — or type

EASY WAY

Tap the QR button (right of Connect), point the camera at the QR code on the PC screen — it connects by itself. Done.

Typing way: copy the amber address into the top box and the pink code into the bottom box, then tap Connect:

A B QR

A address box · B code box · QR the scan button

PocketPad remembers your PC — from the second time on, it's just open → Connect. Both devices must be on the same Wi-Fi (or the PC's own hotspot).

That's the routine. Desktop icon → scan (or tap Connect) → start the game. About fifteen seconds once you've done it twice.

The controller

Hold the phone sideways. Left thumb rides the cross — slide it, don't tap it: diagonals happen automatically where the arms meet. Right thumb takes the coloured buttons — and pressing between two buttons hits both at once, which is how you do Tekken's two-button moves with one thumb.

Make it yours

Tap the ⚙ gear at the top of the gamepad.

SettingWhat it does
Customize layout Drag the cross and the buttons anywhere your thumbs prefer, and resize them with the sliders. Save layout keeps it forever; Reset puts everything back.
Vibrate on press A tiny tick each time a button registers — helps you feel the buttons without looking. The slider underneath sets the power from 0 to 100% and buzzes a preview when you let go. Off switches it off entirely.
Mouse speed How fast the pointer moves in mouse mode.

Play with friends

Up to 4 phones can join the same PC at once — each one becomes its own controller, so two phones means player 1 vs player 2.

HowDetail
Joining Every phone scans the same QR (or types the same address and code). While anyone is connected, the PC window keeps showing a small QR for the next phone.
Who is who The PC window lists each phone as P1–P4 with its own delay. The first to connect is player 1, and slots are re-used when someone leaves.
In the game The game sees separate Xbox controllers — pick Versus/local multiplayer like you would with real pads. Nothing extra to set up.

Mouse mode

A controller can't double-click a desktop icon. Tap Mouse at the top of the gamepad and the phone becomes a laptop-style trackpad; tap Gamepad to switch back.

Why PocketPad asks for administrator. Mouse mode moves the real Windows pointer, and Windows only lets a program do that to windows running at the same permission level or lower. Without administrator, the pointer froze the moment anything running as administrator took the focus — Task Manager, an admin command prompt, a game started as admin — and the usual way to land there is simply minimising PocketPad so something else comes forward. Answering Yes to the prompt when PocketPad starts is what keeps the pointer working everywhere.

If it doesn't work

ProblemFix
Connect fails 1. Same Wi-Fi on both?  2. Is the PC window open?  3. Scan the QR instead of typing — it can't mistype.
“That code has expired” The code renews every time the PC app opens. Use the one on screen right now — or just scan the QR.
Game doesn't react Connect first, then start the game. Already running? Restart it.
Delay number is orange Move closer to the router or pause downloads. The PC's own hotspot is often faster than a busy router.
Disconnects on its own Android's battery saver is pausing PocketPad. Phone Settings → battery → turn optimisation off for PocketPad.
Can't find the PC window It's tucked next to the clock, bottom-right of Windows. Double-click its little icon there to bring it back.
Mouse pointer won't move PocketPad needs to be running as administrator — say Yes to the prompt when it starts. Windows blocks a normal program from moving the pointer while a window running as administrator has the focus, so without it the pointer stops the moment you minimise PocketPad or click an admin window. If you said No, close PocketPad and open it again.
Buttons work but the mouse doesn't Same cause as above: the gamepad goes through a virtual controller, which Windows never restricts, while the mouse moves the real pointer, which it does. Restart PocketPad and accept the administrator prompt.
