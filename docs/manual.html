How to play with PocketPad

Your phone becomes the controller. Your PC runs the game. Connecting them takes three steps and about twenty seconds.

BLUE = do this on the PC GREEN = do this on the phone
1

On the PC

Double-click “PocketPad Link” on the desktop

A small black window opens. It shows the two things you are about to type into the phone — highlighted below:

PocketPad Link
 P O C K E T P A D   L I N K        v0.1
 ==========================================
 Controller ready.

 Open PocketPad on your phone and enter:

     PC address   192.168.1.89
     Code         b9950694

 Waiting for the phone...

Your numbers will be different — read them from your window, not from this picture. The Code is new every time you open PocketPad Link. Keep this window open while you play; closing it unplugs the controller.

2

On the phone

Open PocketPad and copy those two things in

PC window saysPC address  192.168.1.89
──▶
Type it in the phone'stop box
PC window saysCode  b9950694
──▶
Type it in the phone'sbottom box

Filled in, it looks like this — then press Connect:

A B TAP

A — the PC address goes in the top box  ·  B — the Code goes in the bottom box

Phone and PC must be on the same Wi-Fi (same router, or the PC's own hotspot). If Connect fails, that's the first thing to check.

3

On the PC

Wait for the green line — then start your game

The PC window adds this line the moment the phone is in:

PocketPad Link
 CONNECTED   realme RMX3430  (192.168.1.87)
 You can start your game now.

Now open the game after connecting — many games only look for a controller while they start. The game sees your phone as a normal Xbox controller. Nothing to set up inside the game.

✔

That's the whole routine. Every time you want to play: open PocketPad Link → type the two values on the phone → Connect → start the game.

The controller

Hold the phone sideways. Left thumb moves, right thumb attacks. The green number at the top is your delay — under 20 ms means instant.

Mouse mode

A controller can't double-click a desktop icon. When you need a mouse — to launch the game, close a pop-up — tap Mouse at the top of the gamepad. Tap Gamepad to go back.

If it doesn't work

ProblemFix
Connect fails 1. Same Wi-Fi on both?  2. Re-read the address — one wrong digit is the usual cause.  3. Is the PC window still open?
“Rejected: token” The code has changed. Type the code the PC window shows right now — yesterday's code never works.
Game doesn't react Connect first, then start the game. If it was already running, restart it.
Delay number is orange Move closer to the router, or pause downloads. The PC's own hotspot is often faster than a busy router.
Disconnects on its own Android's battery saver is putting PocketPad to sleep. In phone Settings, turn battery optimisation off for PocketPad.
